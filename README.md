# fossa_soundscape
Biotic, Abiotic, and Anthropogenic Contributors to Soundscapes: Development of  an Open-Source Method for Data Integration &amp; Visualization  

This repository is related to the above titled project, funded by NOAA"s Ocean Acoustics Program. In an effort to encourage open science, all deliverables and data products resulting from this collaborative project will be made publicly available. 

Project development (tasks, digital conversations) will be archived on the projects page (https://github.com/users/shannonrankin/projects/2). Please assign tasks to others as needed. 

Final Report can be found here as a pdf.
